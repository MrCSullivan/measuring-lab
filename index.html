          Turn on one shared board for every device

          Right now each device keeps its own board. To pool every laptop and iPad into class leaderboards, the game needs a Google Sheet of your own to write to. It takes about ten minutes.

          1. Make a new Google Sheet, then choose Extensions → Apps Script.
          2. Paste the leaderboard script (the .gs file that came with this game) into Code.gs, replacing what is there.
          3. Add an HTML file named exactly Page (the + beside Files) and paste this whole game file into it.
          4. Choose Deploy → New deployment → Web app. Execute as Me, who has access Anyone. The address it gives you, ending /exec, is the link children open.
          5. Add one tab to the sheet for each class, named for its class code (for example 5Semmler). Children type that code before their name, so make codes hard to guess.
          6. Reopen the sheet. In the new Measuring Lab menu choose Set teacher name and password. To use the teacher buttons, type that name on the game's name screen and then the password.
